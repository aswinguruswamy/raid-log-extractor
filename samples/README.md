# Sample notes

Ten call notes for testing and evaluation (story S2-01, KAN-15). All names, companies, and projects are invented. No real client data.

| File | Project type | Format | What it tests |
|---|---|---|---|
| s01_mobile_release.vtt | Software release | Teams transcript | Small talk; an action agreed in two turns ("can you…?" / "Sure") |
| s02_crm_migration.txt | Data migration | Bullet notes | An action with no owner |
| s03_payroll_vendor.vtt | Vendor change | Zoom transcript | Relative dates ("this week") must not become dates |
| s04_office_move.txt | Office move | Formal minutes | A context date that is not a due date |
| s05_erp_steering.docx | ERP rollout | Word, with an action table | Owners and dates from a table; "Not set" date |
| s06_holiday_campaign.txt | Marketing campaign | Terse shorthand | First names only; "AI:" means action item |
| s07_cloud_migration.vtt | Cloud migration | Teams transcript | A decision that changes during the call (only the final one counts) |
| s08_graduate_onboarding.docx | HR programme | Word, prose | Owner given by first name only ("Mei") |
| s09_audit_prep.txt | Compliance audit | Formal notes | A date line that is context, not an item |
| s10_standup.vtt | Daily stand-up | Zoom transcript | Mostly small talk: only 2 real items (tests false positives) |
